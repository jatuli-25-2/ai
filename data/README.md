# 학습 데이터 안내

감정분류 모델 Fine-tuning에는 AI Hub의 감정 대화 데이터를 사용했습니다.

- 데이터 출처: AI Hub
- 데이터셋: 감정이 태깅된 자유대화 데이터
- 프로젝트에서 사용하는 입력 컬럼: `발화문`
- 프로젝트에서 사용하는 정답 컬럼: `1번 감정`

AI Hub 데이터셋 페이지:
https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=263

## 데이터 파일 준비

원본 또는 학습용으로 가공한 데이터는 공개 Git 저장소에 포함하지 않습니다.

학습을 실행하려면 AI Hub의 이용 조건을 확인한 뒤 데이터를 별도로 내려받아, 학습 코드가 읽을 수 있도록 다음 경로에 준비하세요.

```text
data/emotion_data.csv
```

현재 `src/emotion_train.py`는 위 CSV에서 `발화문`, `1번 감정` 컬럼을 읽습니다.

> 데이터의 다운로드·이용·재배포 여부는 AI Hub의 해당 데이터셋 이용 조건을 따릅니다.
